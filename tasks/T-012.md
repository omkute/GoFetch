# T-012: Bandwidth Limiter & Rate Limiting Engine

* **Milestone**: 4 (GoFetch v2 — Control, Persistence & GUI)
* **Dependencies**: `T-011`
* **Status**: Completed
* **Scope**:
  * Implement thread-safe token-bucket rate limiter in `internal/engine/limiter.go`.
  * Support global engine limit and per-download limit with dynamic reconfiguration (`SetLimit(bps int64)`).
  * Implement `LimitedReader` wrapping `io.Reader` for streaming chunk reads.
  * Integrate rate limiting into `internal/engine/worker.go` and `internal/engine/options.go`.
  * Add `--rate-limit` flag support to `cmd/gofetch/add.go` and `cmd/gofetch/daemon.go` with human-readable string parsing (e.g., `5MB`, `500KB`, `10M`).
* **Deliverables**:
  * `internal/engine/limiter.go`, `internal/engine/limiter_test.go`
  * `internal/engine/worker.go`, `internal/engine/options.go`
* **Testable Outcome**:
  * Unit tests verify that reading through `LimitedReader` throttles transfer throughput within expected variance across concurrent workers without data races under `-race`.
