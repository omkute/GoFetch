# T-007: Priority Queue & Task Scheduling

* **Milestone**: 1 (Engine Core)
* **Dependencies**: `T-004`
* **Status**: Completed
* **Scope**:
  * Implement thread-safe priority heap in `internal/queue/priority_heap.go` using `container/heap`.
  * Define download task model in `internal/queue/task.go` with priorities (`PriorityHigh`, `PriorityNormal`, `PriorityLow`) and lifecycle states (`StatusEnqueued`, `StatusActive`, `StatusPaused`, `StatusCompleted`, `StatusFailed`).
  * Implement task scheduler in `internal/queue/scheduler.go` managing concurrent task slots and dispatching highest priority tasks first with FIFO tie-breaking on creation timestamp.
* **Deliverables**:
  * `internal/queue/priority_heap.go`, `internal/queue/task.go`, `internal/queue/scheduler.go`
  * `internal/queue/priority_heap_test.go`, `internal/queue/scheduler_test.go`
  * `examples/scheduler_demo/main.go`
* **Testable Outcome**:
  * Enqueueing mixed priority tasks (Low, Normal, High) into a capacity-limited scheduler dispatches and executes High priority tasks before Normal and Low tasks regardless of submission order.
  * Verified passing via `go test -v -race ./...` and `make test`.
