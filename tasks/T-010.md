# T-010: Daemon Local REST API & IPC Integration

* **Milestone**: 3 (Daemon, IPC & Observability)
* **Dependencies**: `T-001`, `T-007`
* **Status**: Completed
* **Scope**:
  * Implement daemon REST endpoints in `internal/api/handlers.go` and `internal/api/routes.go`:
    * `POST /api/v1/downloads` (Enqueue new download job)
    * `GET /api/v1/downloads` (List active and queued downloads)
    * `GET /api/v1/downloads/{id}` (Get job status and per-chunk metrics)
    * `POST /api/v1/downloads/{id}/pause` & `POST /api/v1/downloads/{id}/resume`
    * `DELETE /api/v1/downloads/{id}` (Cancel/remove download)
  * Implement CLI commands in Cobra (`cmd/gofetch/add.go`, `cmd/gofetch/list.go`, `cmd/gofetch/pause.go`, `cmd/gofetch/resume.go`) communicating with the daemon over local HTTP.
* **Deliverables**:
  * `internal/api/handlers.go`, `internal/api/models.go`, `internal/api/routes.go`, `internal/api/server.go`
  * `cmd/gofetch/add.go`, `cmd/gofetch/list.go`, `cmd/gofetch/pause.go`, `cmd/gofetch/resume.go`
  * `internal/api/handlers_test.go`, `cmd/gofetch/client_test.go`
* **Testable Outcome**:
  * Tests verify end-to-end REST lifecycle: submitting a download via `POST`, listing it via `GET`, pausing and resuming via `POST`, and querying details via `GET /{id}`.
