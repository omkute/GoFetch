# T-011: Asynchronous Event Bus & Off-Hot-Path Telemetry

* **Milestone**: 3 (Daemon, IPC & Observability)
* **Dependencies**: `T-010`
* **Status**: Completed
* **Scope**:
  * Implement non-blocking asynchronous event bus in `internal/state/event_bus.go` using buffered channels.
  * Define core lifecycle event types:
    * `EventDownloadStarted`
    * `EventChunkCompleted`
    * `EventDownloadFinished`
    * `EventDownloadFailed`
  * Support fan-out pub/sub subscription:
    * `Subscribe(types ...EventType) <-chan Event`
    * `Publish(evt Event)` guaranteeing non-blocking dispatch under high contention or slow consumers (drop-on-full or bounded buffer with overflow counter).
  * Implement optional PostgreSQL consumer in `internal/state/postgres.go` via `pgx/v5` running in an isolated background goroutine with batch flushing.
  * Invariant Verification: Zero DB queries, zero connection locks, zero blocking I/O on the chunk transfer hot path.
* **Deliverables**:
  * `internal/state/event_bus.go`, `internal/state/postgres.go`
  * `internal/state/event_bus_test.go`, `bench/bench_telemetry_test.go`
  * `examples/telemetry_demo/main.go`
* **Testable Outcome**:
  * Tests verify non-blocking event publishing (a blocked subscriber does not block `Publish`), channel fan-out, and graceful shutdown.
  * Benchmark confirms that streaming throughput and latency remain completely unaffected by telemetry subscribers.
