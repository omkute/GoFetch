# T-006: Media Classifier & Directory Routing

* **Milestone**: 1 (Engine Core)
* **Dependencies**: `T-002`
* **Status**: Completed
* **Scope**:
  * Implement content type detection in `internal/classifier/classifier.go` and `internal/classifier/rules.go`.
  * Support sniffing file magic bytes (combining `http.DetectContentType` with custom binary signatures for ISO, DMG, RAR, 7z, MP4, MKV, MP3, PDF, EXE, ELF, ZIP, etc.) and file extension fallbacks.
  * Implement post-download directory routing in `internal/classifier/router.go`, atomically relocating (`os.Rename`) completed downloads to organized subfolders (`Videos/`, `Documents/`, `Audio/`, `Archives/`, `Software/`, `Images/`, `Miscellaneous/`).
* **Deliverables**:
  * `internal/classifier/classifier.go`, `internal/classifier/rules.go`, `internal/classifier/router.go`
  * `internal/classifier/classifier_test.go`, `internal/classifier/router_test.go`
  * `examples/classifier_demo/main.go`
* **Testable Outcome**:
  * Feeding completed downloads (including files with misleading extensions, like an MP4 named `payload.bin`, a PDF, a ZIP, or a binary executable) accurately identifies their media category and moves them into the corresponding sorted folder on disk.
  * Verified passing via `go test -v -race ./...` and `make test`.
