# T-016: Embedded Modern Desktop / Web GUI

* **Milestone**: 4 (GoFetch v2 — Control, Persistence & GUI)
* **Dependencies**: `T-015`
* **Status**: Completed
* **Scope**:
  * Build zero-dependency, self-contained single-page web GUI in `internal/web/static/` (HTML5, modern CSS, Vanilla JS).
  * Embed assets into the Go binary using `embed.FS` in `internal/web/embed.go`.
  * Implement real-time Canvas speed history chart, category drawer, queue status filter, and multi-chunk progress views.
  * Connect frontend directly to daemon SSE stream (`/api/v1/events`) and REST endpoints.
  * Wire web handler into `internal/api/routes.go` at `/`.
* **Deliverables**:
  * `internal/web/embed.go`, `internal/web/static/index.html`, `internal/web/static/style.css`, `internal/web/static/app.js`
  * `internal/api/routes.go`
* **Testable Outcome**:
  * HTTP test confirms that `GET /` serves the embedded HTML GUI with `200 OK` and `text/html` content type.
